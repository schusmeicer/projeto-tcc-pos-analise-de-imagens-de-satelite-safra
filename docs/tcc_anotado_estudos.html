1. A Arquitetura do Modelo (O Coração do TCC)

Texto do TCC: "A arquitetura proposta baseia-se em um modelo de aprendizado de máquina em duas etapas (detrending híbrido). Uma regressão linear múltipla modela a tendência secular e um XGBoost atua nos resíduos."
💡 TRADUÇÃO: Por que fizemos um modelo Híbrido?

Imagine que a soja é um elevador. A cada ano que passa, a genética das sementes melhora, e o "teto" de produção sobe. Os modelos modernos (como XGBoost e Random Forest) são burros para entender a passagem do tempo: se no passado a soja produzia no máximo 3.000 kg/ha, a árvore de decisão acha que é impossível produzir 3.800 kg/ha no futuro, mesmo com clima perfeito.

A Solução Híbrida: Nós botamos uma Regressão Linear Clássica para fazer o trabalho pesado: calcular o ganho tecnológico (o elevador que sobe 26 kg/ha por ano). Depois, nós chamamos o XGBoost e dizemos: "XGBoost, a regressão já acertou a média histórica. Seu trabalho agora é olhar pro Clima e pro Satélite e me dizer se esse ano a safra vai quebrar ou vai ser recorde". Ou seja, a Regressão Linear olha para o Tempo, e o XGBoost olha para o Clima.

2. A Tabela 2 e as Métricas (WMAPE e MAE)

Texto do TCC: "Na validação Out-of-Time, o modelo híbrido obteve WMAPE de 7,24% e MAE de 251 kg/ha, superando as versões de árvores puras."
💡 TRADUÇÃO: Lendo a Tabela 2

Por que não ligamos para o R²? A banca ama o R², mas o R² pune modelos que tentam prever números maiores do que os vistos no treino (como safras recordes). Diga à banca que o R² não paga os boletos do fazendeiro. O que importa é errar poucas sacas.

MAE (Erro Absoluto): 251 kg/ha. Uma saca de soja tem 60 kg. Isso significa que o nosso modelo erra, na média, cerca de 4 sacas por hectare. Isso é incrivelmente bom para a escala de um estado inteiro.

WMAPE: É a porcentagem de erro (7,24%). O "W" vem de Weighted (Ponderado). Significa que nós demos mais peso para os erros cometidos em Sorriso e Mutum (cidades gigantes) do que em cidades que plantam pouca soja. Errar 10% num município pequeno não afeta o estado. Errar 10% em Sorriso quebra a previsão do PIB.

Por que a Tabela 2 é a nossa prova de ouro? Porque ela mostra que o XGBoost Puro teve 8,20% de erro. Quando juntamos a Regressão Linear com o XGBoost (Híbrido), o erro caiu para 7,68% (e depois 7,24% com ajuste fino). A Tabela prova que a sua invenção da arquitetura Híbrida salvou dinheiro real e superou a IA pura.

4. Testes Estatísticos (Moran, Spearman e VIF)

💡 TRADUÇÃO: O que são essas palavras difíceis?

1. Índice de Moran (Autocorrelação Espacial): Deu p > 0,05. Isso quer dizer que o modelo não é enviesado por vizinhança. Ele não acerta uma cidade só porque a cidade do lado é boa. Ele acerta porque leu o clima e o satélite direito. O erro dele é bem espalhado no mapa (ruído branco).

2. Spearman (Heterocedasticidade): O p-valor deu 0,0012 (rejeita a tese de que o erro é perfeitamente igual em todo lugar). O Spearman (rho) deu -0,16. O que isso quer dizer? O modelo erra um pouquinho mais quando tenta prever uma safra que quebrou muito por causa de uma seca brutal, e acerta mais fácil em anos normais. Você fala para a banca: "Isso é biologia pura. Eventos extremos como secas pesadas são caóticos, é normal a máquina ter um pouco mais de incerteza matemática neles."

3. VIF (Multicolinearidade): Deu > 10. O NDVI (satélite) e o EVI (satélite) medem a mesma coisa (o verde da planta). Colocar os dois numa regressão linear faz a regressão "ficar maluca". Por isso (fale isso com orgulho), nós não botamos o NDVI na Regressão Linear, nós deixamos o NDVI só pro XGBoost! Árvores de decisão não sofrem de multicolinearidade. Essa é outra genialidade do modelo Híbrido.

5. SHAP (A Importância das Variáveis)

💡 TRADUÇÃO: Como ler o gráfico com bolinhas coloridas (Figura 5)

O SHAP mostra o cérebro da Inteligência Artificial. Eixo X é o impacto na sacaria (pra direita soma saco de soja, pra esquerda tira saco de soja). A cor rosa é quando o valor choveu muito/esquentou muito.

  • def_j2 (Déficit Hídrico no Enchimento): Quando falta água (rosa), as bolinhas puxam um pouco pra esquerda (tira soja). Mas quando sobra água (azul), as bolinhas estouram pra direita (+200 kg/ha). O modelo sabe que chuva na hora certa é prêmio!
  • tmean_j2 (Calor no Enchimento): Bolinhas rosas estão à esquerda. Muito calor aborta flor e vagem da planta = quebra de safra.
  • NDVI_j1 (Vigor no Crescimento): Ajuda a empurrar pra cima a previsão quando é verde (rosa). É o satélite dizendo "a lavoura nasceu bonita".

Código 1: A Arquitetura do Modelo Híbrido (hybrid_model.py)

import numpy as np from sklearn.base import BaseEstimator, RegressorMixin from sklearn.linear_model import LinearRegression from sklearn.utils.validation import check_is_fitted # A nossa classe personalizada que junta a Estatística Clássica com IA Moderna class HybridDetrendingRegressor(BaseEstimator, RegressorMixin): def __init__(self, base_estimator): # base_estimator é o nosso XGBoost que vai ser passado como parâmetro self.base_estimator = base_estimator # Instancia a regressão linear que vai descobrir a reta do ganho tecnológico (ano) self.linear_model = LinearRegression() def fit(self, X, y): # 1º Passo: Treinar a regressão linear na produtividade real (y) self.linear_model.fit(X, y) # 2º Passo: Pedir para a regressão linear prever a safra. linear_pred = self.linear_model.predict(X) # 3º Passo: O pulo do gato! Calcula o RESÍDUO. # Resíduo = Real - Previsto_pela_Regressao. # É a diferença entre a reta "perfeita" e o que o clima bagunçou de verdade. residuals = y - linear_pred # 4º Passo: Treina o XGBoost para aprender SÓ os resíduos (o erro do clima). self.base_estimator.fit(X, residuals) self.is_fitted_ = True return self def predict(self, X): # Quando pedimos para o modelo prever o futuro (2024)... check_is_fitted(self, 'is_fitted_') # Ele primeiro calcula onde a reta do ano deveria estar... linear_pred = self.linear_model.predict(X) # Depois, o XGBoost olha o clima de 2024 e diz quanto deve somar ou subtrair... residual_pred = self.base_estimator.predict(X) # Resultado final: A reta base + a punição/prêmio do clima! return linear_pred + residual_pred

Código 2: Como calculamos as métricas (o WMAPE)

def calc_metrics(y_true, y_pred, area): # MAE: Erro Absoluto Médio. Simplesmente o módulo da diferença. Ex: Errou por 200 kg. mae = np.mean(np.abs(y_true - y_pred)) # WMAPE (Erro Percentual Ponderado): A métrica Rainha! # Em vez de fazer uma média simples, nós multiplicamos o erro absoluto de cada município # pela 'area' (hectares plantados). Depois dividimos pelo total produzido. # Por que? Para o modelo não ser "premiado" por acertar cidadezinhas minúsculas # e ser destruído por errar as capitais do agro como Sorriso. numerador = np.sum(np.abs(y_true - y_pred) * area) denominador = np.sum(y_true * area) wmape = (numerador / denominador) * 100 return mae, wmape
